# Vedic Climate Scope v2.3

Static HTML/CSS/JavaScript. No Vite.

## New in v2.3
- Added a deterministic, concise Location Horoscope engine to the bottom panel.
- All eight horoscope tabs now generate a short reading from the selected blue-dot location.
- Forecasts use a maximum of four visible parts: Theme, What may show up, Best use, and Watch for.
- Bhavat Bhavam, aspects, nakshatra lord, transit governors, climate house, sign tone, and personalized planet/house roles are used as background factors instead of separate repetitive paragraphs.
- Repeated or equivalent influences are deduplicated before rendering.
- A "Why this forecast?" disclosure shows the technical astrology only when requested.
- Birth data remains optional; manual planet and house roles can personalize the reading.

## Deployment
Replace the existing repository files with these four files and commit. Vercel should redeploy automatically.
